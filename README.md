# ESP32 Dev Board - GPS Data to TFT 1.8" Round Display

Development Environment: VS Code - PlatformIO

## Hardware
- [ESP32 Dev Board](https://www.amazon.com/gp/product/B08246MCL5)
- [GC9A01 TFT Display](https://www.amazon.com/gp/product/B0B7TFRNN1)
- [WaveShare LC76G](https://www.waveshare.com/lc76g-gnss-module.htm)

## Library Dependancies:
  - tinyu-zhao/TinyGPSPlus-ESP32@^0.0.2
  - bodmer/TFT_eSPI @ ^2.5.43
  - lvgl/lvgl @ ^9.2.2
